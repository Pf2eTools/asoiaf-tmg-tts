# SteamCloudUploader
Manually uploading assets to the tts steam cloud is very cumbersome if you need to know their urls.

I wrote `cloud-uploader.py` because I find it easier to write something quick and dirty in python. Please excuse the janky custom .dll setup.

Shortly after writing this script however, we pivoted to hosting images for the cards on GitHub, so it was only ever used to upload 3d assetbundles, which we didn't want to host on a public repository at the time.
